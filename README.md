# web · páginas públicas de Extensión Digital

Repositorio **público**. Aquí vive todo lo que se publica en internet a través de
GitHub Pages, bajo el dominio `extensiondigital.cl`.

## Qué hay aquí

| Archivo | Qué es |
|---------|--------|
| `index.html` | Portada de Extensión Digital. Diseño e identidad visual documentados fuera de este repositorio |

## Importante

Todo lo que se sube a este repositorio es **visible para cualquiera**, incluido el
código fuente de las páginas. Nunca poner aquí:

- Documentos de gestión, estrategia o modelo de negocio → esos van fuera de este repositorio
- Claves de API, contraseñas o tokens
- Datos personales de clientes

## Repositorio relacionado

La gestión del proyecto (plan, casos de uso, modelo de negocio, bitácora) vive en un
repositorio **privado** aparte.
